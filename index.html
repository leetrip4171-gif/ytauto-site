쇼핑쇼츠 쿠팡파트너스

제품 영상을 넣으면 영상 속 제품이 무엇인지 먼저 읽고, 쿠팡에서 같은 제품을 찾아 딥링크를 만든 뒤 대본·내레이션·한글 자막·모델샷 썸네일을 붙여 세로 영상으로 완성합니다.

  • 설명란 첫 줄에 쿠팡파트너스 고지문 자동 삽입
  • 제품 후보를 영상과 비교해 일치도를 매겨 줍니다
  • 영상에서 중요한 장면만 골라 이어 붙입니다
  • 한 편에 약 2~3분

실시간 속보 영상 뉴스

실시간 검색어 1위(또는 직접 넣은 주제)를 언론사 두 곳으로 확인한 뒤 12~15컷 대본, AI 이미지, 음성, 자막을 만들어 뉴스 카테고리로 올립니다.

  • 확인한 것 / 확인 못 한 것 / 출처를 설명란에 자동 기재
  • AI 이미지 사용 고지 포함
  • 피의자·피해자 신상은 넣지 않습니다
  • 한 편에 약 5분

사람이 하던 확인을 대신합니다

예전에는 키워드를 적고 제품을 고르고 결과를 눈으로 봐야 했던 부분입니다.

영상을 먼저 읽습니다

넣은 영상을 통째로 분석해 제품의 생김새·기능·장면별 중요도를 정리합니다. 확인된 것과 추측인 것을 나눠 두어, 대본에 근거 없는 말이 들어가지 않게 막습니다.

키워드를 비워도 됩니다

검색어를 안 적으면 영상 분석 결과로 검색어를 스스로 정합니다. 찾은 후보마다 영상 속 제품과 얼마나 같은지 점수를 매겨 정렬하고, 애매하면 사람에게 확인을 받습니다.

중요한 장면만 골라서

영상 전체를 그대로 쓰지 않고 제품이 가장 잘 보이는 구간을 골라 이어 붙입니다. 내레이션이 끝나면 2초 뒤 영상도 끝납니다.

올리기 전 마지막 검수

금지 표현, 자막 줄 수와 길이, 소리 크기, 검은 화면, 제품이 안 보이는 구간, 고지문 위치까지 한 번에 검사합니다. 걸리면 올리지 않고 멈춥니다.

설치

압축 풀고 더블클릭이 전부입니다

윈도우

  1. zip 내려받아 압축 풀기

    바탕화면이나 문서 폴더에. 폴더 이름은 그대로 두세요.

  2. 시작.bat 더블클릭

    파이썬이 없으면 설치 페이지가 열립니다. 설치한 뒤 다시 더블클릭.

  3. 기다리기

    처음엔 ffmpeg(90MB)과 파이썬 패키지를 내려받습니다. 끝나면 브라우저에 화면이 뜹니다.

「Windows의 PC 보호」가 뜨면 「추가 정보」 → 「실행」.

맥

  1. zip 내려받아 압축 풀기

    다운로드 폴더에서 더블클릭하면 풀립니다.

  2. 시작.command 우클릭 → 열기

    처음 한 번 「확인되지 않은 개발자」가 뜨면 우클릭 → 열기 → 열기. 그다음부턴 더블클릭.

  3. ffmpeg 없다고 하면

    터미널에 brew install ffmpeg 입력 후 다시 실행. (Homebrew가 없으면 brew.sh)

화면 주소는 http://127.0.0.1:8790/ — 내 컴퓨터에서만 열리는 주소입니다. 끌 때는 화면의 「종료」.

첫 실행

딱 네 번만 하면 됩니다

  1. 「설정」 탭에 키 넣고 「저장하고 점검」

    Gemini 키, 쿠팡파트너스 Access·Secret. 점검 결과가 초록으로 바뀌면 됩니다.

  2. 계정 연결

    유튜브는 구글 계정으로 허용. 인스타·스레드를 쓸 거라면 여기서 같이 연결해 둡니다. 올라갈 채널 이름이 화면에 계속 보이니 확인하세요.

  3. input_videos 폴더에 내 영상 넣기

    mp4 또는 mov. 제품이 잘 보이는 10~60초 영상이 좋습니다.

  4. 「쇼핑쇼츠」 탭에서 영상 고르고 「실행」

    키워드와 쿠팡 주소는 비워도 됩니다. 애매하면 후보를 보여 주니 영상 속 제품과 같은 것을 고르세요.

쇼츠 썸네일: 유튜브가 쇼츠 맞춤 썸네일을 자동으로 안 받는 경우가 있습니다. 결과 화면의 「썸네일 파일 보기」로 thumb.jpg를 찾고, 스튜디오의 썸네일 칸에 끌어다 놓고 저장하면 됩니다. 30초면 끝납니다.

지켜야 하는 것

이건 프로그램이 대신해 주지 않습니다

  • 본인이 촬영했거나 허락받은 영상만 씁니다. 판매자 영상, 남의 얼굴이 나오는 영상은 올리면 안 됩니다.
  • 쿠팡파트너스 고지문은 자동으로 설명란 첫 줄에 들어갑니다. 지우지 마세요.
  • 대본은 「써 봤다·내돈내산」 같은 거짓 체험 표현과 「최저가·마감임박」 같은 확인 안 되는 말을 쓰지 않도록 되어 있습니다.
  • 속보 영상은 확인 안 된 내용을 확인 안 됐다고 말하고, 피의자·피해자 신상은 넣지 않습니다.
  • 키와 토큰은 내 컴퓨터에만 있습니다. 프로그램 폴더를 남에게 통째로 보내지 마세요.
질문

자주 묻는 것

돈이 드나요?

프로그램은 무료입니다. Gemini API·타입캐스트·R2는 각자 계정의 사용량만큼 과금됩니다(Gemini는 무료 한도가 있고, R2는 이 정도 사용량이면 무료 한도 안입니다). 유튜브·쿠팡파트너스·Meta는 무료.

「유튜브 연결」에서 허용 화면이 안 떠요

운영자 앱의 테스트 사용자로 등록돼야 합니다. 구글 계정 주소를 운영자에게 알려 주세요. 등록 후 다시 「유튜브 연결」.

쿠팡 검색 결과가 없다고 나와요

키워드를 더 일반적인 말로 바꿔 보세요(예: 「스텐 반죽판」 → 「반죽판」). 쿠팡 검색은 시간당 횟수 제한이 있어 같은 키워드는 24시간 재사용합니다.

영상에 얼굴이 나오면요?

올리지 마세요. 프로그램은 얼굴을 지우지 않습니다. 손·몸만 나오는 영상은 괜찮습니다.

포트 8790을 못 연다고 나와요

이미 켜져 있는 겁니다. 브라우저에서 http://127.0.0.1:8790/을 열거나, 화면의 「종료」 후 다시 실행하세요.

윈도우에서 한글이 깨져 보여요

검은 창의 글자만 깨지는 것이면 동작에는 문제없습니다. 화면(브라우저)은 정상입니다.

업데이트는 어떻게 하나요?

새 zip을 받아 압축을 풀고, 옛 폴더의 config·input_videos·output 폴더를 새 폴더로 옮기면 됩니다.

만든 사람: 기행채널 (이기행). 문의는 당근 모임 「AI로 수익화 실현하기」 채팅으로. 여기서는 프로그램 안내만 하고, 어떤 키도 받지 않습니다.
