쇼핑쇼츠 쿠팡파트너스

제품 영상을 넣으면 영상 속 제품이 무엇인지 먼저 읽고, 쿠팡에서 같은 제품을 찾아 딥링크를 만든 뒤 대본·내레이션·한글 자막·모델샷 썸네일을 붙여 세로 영상으로 완성합니다.

  • 설명란 첫 줄에 쿠팡파트너스 고지문 자동 삽입
  • 영상 우측 상단에 「광고」 표기 6초 자동 삽입 — 쿠팡파트너스 원칙(최소 5초)
  • 제품 후보를 영상과 비교해 일치도를 매겨 줍니다
  • 내레이션이 끝나면 2초 뒤 영상도 끝납니다
  • 한 편에 약 2~3분

실시간 속보 영상 뉴스

실시간 검색어 1위(또는 직접 넣은 주제)를 언론사 두 곳으로 확인한 뒤 12~15컷 대본, AI 이미지, 음성, 자막을 만들어 뉴스 카테고리로 올립니다.

  • 확인한 것 / 확인 못 한 것 / 출처를 설명란에 자동 기재
  • AI 이미지 사용 고지 포함
  • 피의자·피해자 신상은 넣지 않습니다
  • 한 편에 약 5분

커뮤니티형 실시간 쇼츠 대화체

디시 실시간베스트·개드립의 화제글과 실시간 검색어를 모아 표로 보여 주고, 고른 소재를 두 사람이 주고받는 대화체 12~15컷 쇼츠로 만듭니다. 별도 폴더 「커뮤니티형실시간쇼츠」로 들어 있습니다.

  • 소재는 사람이 고릅니다 — 승인 전에는 돈 드는 단계가 시작되지 않습니다
  • 남녀 목소리 두 사람 · 화자별 자막색
  • 원글 주소를 설명란에 자동 기재 · AI 이미지 고지 포함
  • 특정 집단 비하·신상은 검사에서 걸러 냅니다
  • 소재를 고르면 업로드까지 혼자 갑니다 — 「일부공개」로 올라가니 영상을 보고 공개로 바꾸면 됩니다

사람이 하던 확인을 대신합니다

예전에는 키워드를 적고 제품을 고르고 결과를 눈으로 봐야 했던 부분입니다.

영상을 먼저 읽습니다

넣은 영상의 장면과 소리를 읽어 말소리·배경음악이 있는지, 화면에 박힌 글자(외국어 자막·워터마크)가 어디 있는지 판정해 가리거나 잘라냅니다. 장면별 중요도까지 점수를 매기는 분석은 다음 배포본 예정입니다.

엉뚱한 상품이면 멈춥니다

검색 키워드는 적어 주셔야 합니다. 찾은 후보마다 영상 속 제품과 얼마나 같은지 점수를 매겨 정렬하고, 화면에서 사람이 「이 제품으로 진행」을 눌러야 넘어갑니다. 적어 둔 쿠팡 주소의 상품을 못 찾으면 다른 상품으로 바꾸지 않고 영상 만들기 전에 멈춥니다.

길이를 내레이션에 맞춥니다

내레이션이 끝나면 2초 뒤 영상도 끝납니다. 뒤에 배경음악만 남는 구간을 두지 않습니다. 제품이 가장 잘 보이는 구간만 골라 이어 붙이는 기능은 다음 배포본 예정입니다.

올리기 전 마지막 검수

해상도·화면비·fps·길이·검은 화면, 소리 크기와 무음, 자막 줄 수·줄폭·타이밍, 썸네일 글자가 얼굴·제품을 가리는지, 고지문 위치와 설명란 링크까지 28가지를 검사합니다. 걸리면 올리지 않고 멈춥니다. 금지 표현은 대본을 만들 때 걸러 냅니다.

설치

압축 풀고 더블클릭이 전부입니다

윈도우

  1. zip 내려받아 압축 풀기

    바탕화면이나 문서 폴더에. 폴더 이름은 그대로 두세요.

  2. 인스톨.bat 더블클릭

    처음 한 번만. 파이썬이 없으면 설치 페이지가 열립니다(설치한 뒤 다시 더블클릭). 브라우저에 설치 마법사가 뜨면 0번부터 8번까지 차례로 — 각 칸의 「사이트 열기」로 가입·키 발급 → 붙여넣기 → 「저장하고 검사」. 유튜브·스튜디오 연결은 「연결」 단추.

  3. 유튜브 연결 전에

    올릴 채널의 구글 이메일을 운영자에게 알려 테스터 명단에 등록받으세요. 명단에 없으면 구글이 「액세스 차단됨」으로 막습니다.

  4. 다음부터는 시작.bat

    마법사가 모두 초록이면 끝. 그 뒤로는 시작.bat 으로 켭니다. 키는 화면 위 「설정」에서 언제든 바꿀 수 있습니다.

「Windows의 PC 보호」가 뜨면 「추가 정보」 → 「실행」.

맥

  1. zip 내려받아 압축 풀기

    다운로드 폴더에서 더블클릭하면 풀립니다.

  2. 인스톨.command 우클릭 → 열기

    처음 한 번 「확인되지 않은 개발자」가 뜨면 우클릭 → 열기 → 열기. 브라우저에 설치 마법사가 뜨면 0번부터 8번까지 차례로 따라 하세요.

  3. ffmpeg 없다고 하면

    터미널에 brew install ffmpeg 입력 후 마법사의 「전체 다시 검사」. (Homebrew가 없으면 brew.sh)

  4. 유튜브 연결 전에

    올릴 채널의 구글 이메일을 운영자에게 알려 테스터 명단에 등록받으세요.

  5. 다음부터는 시작.command

    마법사가 모두 초록이면 끝.

화면 주소는 http://127.0.0.1:8790/ — 내 컴퓨터에서만 열리는 주소입니다. 끌 때는 화면의 「종료」.

첫 실행

딱 네 번만 하면 됩니다

  1. 「설정」 탭에 키 넣고 「저장하고 점검」

    Gemini 키, 쿠팡파트너스 Access·Secret. 점검 결과가 초록으로 바뀌면 됩니다.

  2. 유튜브 채널 연결

    「+ 채널 추가 연결」 → 구글 계정으로 허용. 채널 하나당 한 번씩 연결합니다. 올라갈 채널 이름이 화면에 계속 보이니 확인하세요.

  3. input_videos 폴더에 내 영상 넣기

    mp4 또는 mov. 제품이 잘 보이는 10~60초 영상이 좋습니다.

  4. 「쇼핑쇼츠」 탭에서 영상 고르고 「실행」

    쿠팡 검색 키워드는 적어 주세요(쿠팡 주소는 비워도 됩니다). 후보를 보여 주니 영상 속 제품과 같은 것을 고르고 「이 제품으로 진행」을 누르세요.

쇼츠 썸네일은 눈으로 확인하세요: 프로그램은 썸네일을 올리기만 하고, 쇼츠에 실제로 걸렸는지는 보장하지 않습니다. 업로드 뒤 스튜디오에서 확인하고
안 걸렸으면 thumb.jpg를 썸네일 칸에 끌어다 놓고 저장하면 됩니다. 30초면 끝납니다.

  • 본인이 촬영했거나 허락받은 영상만 씁니다. 판매자 영상, 남의 얼굴이 나오는 영상은 올리면 안 됩니다.
  • 쿠팡파트너스 고지문은 자동으로 설명란 첫 줄에 들어갑니다. 지우지 마세요.
  • 대본은 「써 봤다·내돈내산」 같은 거짓 체험 표현과 「최저가·마감임박」 같은 확인 안 되는 말을 쓰지 않도록 되어 있습니다.
  • 속보 영상은 확인 안 된 내용을 확인 안 됐다고 말하고, 피의자·피해자 신상은 넣지 않습니다.
  • 키와 토큰은 내 컴퓨터에만 있습니다. 프로그램 폴더를 남에게 통째로 보내지 마세요.
질문

자주 묻는 것

돈이 드나요?

프로그램은 무료입니다. Gemini API·타입캐스트는 각자 계정의 사용량만큼 과금됩니다(Gemini는 무료 한도가 있습니다). 유튜브·쿠팡파트너스는 무료.

「유튜브 연결」에서 허용 화면이 안 떠요

config 폴더에 youtube_client_secret.json(본인이 만든 OAuth 앱 파일)이 있는지 먼저 보세요. 그리고 본인의 구글 클라우드 화면에서 내 계정을 테스트 사용자로 등록해야 합니다. 「확인되지 않은 앱」이 뜨면 → 고급 → (안전하지 않음)으로 이동.

일주일쯤 지나면 유튜브 연결이 끊깁니다

프로그램의 제한이 아닙니다. 구글 OAuth 앱을 「테스트(Testing)」 상태로 두면 구글이 발급한 로그인 권한을 7일 뒤 만료시킵니다(구글 공식 정책). 「+ 채널 추가 연결」을 다시 한 번 누르면 됩니다. 매주 다시 하기 싫으면 본인의 앱을 구글 심사에 올려 「게시(In production)」 상태로 바꿔야 합니다. 참고로 테스트 사용자는 최대 100명까지만 등록됩니다.

인스타그램·스레드에도 올라가나요?

v2.0부터 선택 기능으로 들어왔습니다. 설정 탭에 인스타·스레드 토큰과 R2 키를 넣으면, 유튜브에 올린 뒤 이어서 올립니다. 비워 두면 유튜브에만 올라갑니다. 실제 게시까지 확인했습니다(2026-09-10). 준비물은 Meta 프로 계정·개발자 앱·R2 계정입니다 — 유튜브보다 손이 더 갑니다.

윈도우에서도 되나요?

윈도우용 실행 파일(시작.bat)과 ffmpeg 자동 설치가 들어 있습니다. 다만 실제 윈도우 PC에서의 최종 확인은 진행 중입니다. 맥은 확인을 마쳤습니다.

쿠팡 검색 결과가 없다고 나와요

키워드를 더 일반적인 말로 바꿔 보세요(예: 「스텐 반죽판」 → 「반죽판」). 쿠팡 검색은 시간당 횟수 제한이 있어 같은 키워드는 24시간 재사용합니다.

영상에 얼굴이 나오면요?

올리지 마세요. 프로그램은 얼굴을 지우지 않습니다. 손·몸만 나오는 영상은 괜찮습니다.

포트 8790을 못 연다고 나와요

이미 켜져 있는 겁니다. 브라우저에서 http://127.0.0.1:8790/을 열거나, 화면의 「종료」 후 다시 실행하세요.

윈도우에서 한글이 깨져 보여요

검은 창의 글자만 깨지는 것이면 동작에는 문제없습니다. 화면(브라우저)은 정상입니다.

업데이트는 어떻게 하나요?

v2.3.2부터 「업데이트」 입구가 있습니다.
① 옛 버전의 검은 창과 크롬 자동화 창을 닫습니다.
② 새 zip을 옛 폴더 옆 새 폴더에 풉니다 (예: C:\ytauto 옆에 C:\ytauto_v2.3.2). 옛 폴더 위에 덮어 풀지 마세요.
③ 새 폴더의 업데이트.bat(맥: 업데이트.command)을 더블클릭합니다. 옛 폴더의 키·유튜브 연결·로그인·설정을 백업한 뒤 새 폴더로 옮기고, 영상이 쌓인 작업 폴더는 크기를 보여 주고 옮길지 묻습니다.
④ 새 폴더의 시작.bat을 실행합니다. 잘 되면 옛 폴더는 직접 지우세요. 문제가 있으면 옛 폴더를 그대로 쓰면 됩니다 — 옛 폴더는 건드리지 않습니다.

config 폴더를 통째로 옮기지 마세요. 새 버전에서 고친 프로그램 설정까지 옛것으로 돌아갑니다.
_설정백업 폴더의 zip에는 키가 들어 있습니다. 남에게 보내지 마세요.

v2.4.4부터 유튜브 OAuth 앱 파일(youtube_client_secret.json)이 배포본에 들어 있습니다(운영자 앱, 테스트 모드). 본인 앱을 따로 만들 필요가 없고, 대신 올릴 채널의 구글 이메일을 운영자에게 알려 명단에 등록받으면 됩니다.

Gemini 점검이 「한도 초과」(429)로 나와요

고장이 아니라 무료 사용량을 다 쓴 것입니다. 오후 4시쯤(미국 자정) 풀립니다. 급하면 aistudio.google.com/apikey → 「API 키 만들기」에서 새 프로젝트에서 만들기를 고르세요. 이미 쓰던 프로젝트에 키만 새로 만들면 다 쓴 한도를 같이 쓰기 때문에 계속 429가 납니다.

내 채널이 아닌 다른 사람 채널에도 올릴 수 있나요?

됩니다. 채널 주인이 유튜브 설정 → 「관리자 추가」에서 내 구글 계정을 관리자로 넣어 주면(브랜드 계정이어야 합니다), 커뮤니티형 폴더의 추가채널_연결을 실행해 별명(예: chulsoo)으로 그 채널을 연결하세요. 브라우저의 「채널 선택」 화면에서 그 사람 채널을 고르는 것이 핵심입니다. 올릴 편의 작업 폴더에 채널.txt(별명 한 줄)를 두면 그 채널로 올라가고, 없으면 내 기본 채널입니다. 유튜브 API 하루 한도(업로드 약 6편)는 채널을 합쳐 셉니다.

점검 배지가 주황색이에요

「처음 설정이 필요합니다」는 키나 유튜브 연결이 아직 없다는 뜻입니다. 화면 위 「설정」에서 키를 넣고 「저장하고 점검」, 유튜브는 인스톨(설치 마법사)의 5·6번 「연결」 단추, 또는 초기설정_연결을 실행하세요. 빨간색만 진짜 오류입니다.

제품 영상 하나로 시작하세요

키는 내 컴퓨터에만 저장됩니다. 설치 마법사를 따라 하면 첫 영상까지 한 번에 갑니다.
