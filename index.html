맥 · 윈도우 · 내 컴퓨터에서 실행

영상 하나 넣으면, 쇼츠가 유튜브에 올라갑니다.

제품 영상을 넣고 「실행」을 누르면 쿠팡 제품 찾기 → 대본 → 세로 변환 → 음성 → 자막 → 썸네일 → 업로드까지 혼자 갑니다. 실시간 검색어로 속보 영상을 만드는 기능도 들어 있습니다.

↓프로그램 내려받기 (zip) 최신 버전 · 약 9MB · 압축 풀고 더블클릭

만들어 주는 것 두 가지

쇼핑쇼츠 쿠팡파트너스

본인이 찍은 제품 영상을 넣으면 쿠팡에서 같은 제품을 찾아 딥링크를 만들고, 6문장 대본·내레이션·한글 자막·모델샷 썸네일을 붙여 세로 영상으로 올립니다.

  • 설명란 첫 줄에 쿠팡파트너스 고지문 자동 삽입
  • 제품 후보는 영상과 비교해 골라 줌 (원하면 직접 확인 후 진행)
  • 한 편에 약 2~3분

실시간 속보 영상 뉴스

실시간 검색어 1위(또는 입력한 주제)를 언론사 2곳으로 확인한 뒤 12~15컷 대본, AI 이미지, 음성, 자막을 만들어 뉴스 카테고리로 올립니다.

  • 확인한 것 / 확인 못 한 것 / 출처를 설명란에 자동 기재
  • AI 이미지 고지 포함
  • 한 편에 약 5분

준비물

키는 전부 내 컴퓨터 안 config/settings.json에만 저장됩니다. 밖으로 보내지 않습니다.

Gemini API 키필수aistudio.google.com/apikey — 대본·제품 매칭·이미지·(음성)에 씀
쿠팡파트너스 키쇼핑쇼츠partners.coupang.com → 링크 생성 → API 키 발급 (Access · Secret 두 개)
유튜브 채널필수구글 계정으로 한 번 「허용」. 그 전에 운영자에게 구글 계정 주소를 알려 테스트 사용자 등록을 받아야 허용 화면이 뜹니다
타입캐스트 키선택typecast.ai — 비우면 Gemini 음성으로 대신 만듭니다
ffmpeg자동윈도우는 처음 실행 때 자동으로 내려받음(약 90MB). 맥은 터미널에서 brew install ffmpeg

설치

윈도우

  1. zip 내려받아 압축 풀기

    바탕화면이나 문서 폴더에. 폴더 이름은 그대로 두세요.

  2. 시작.bat 더블클릭

    파이썬이 없으면 설치 페이지가 열립니다. 설치 후 다시 더블클릭.

  3. 기다리기

    처음엔 ffmpeg(90MB)과 파이썬 패키지를 내려받습니다. 검은 창에 진행률이 보이고, 끝나면 브라우저에 화면이 뜹니다.

「Windows의 PC 보호」가 뜨면 「추가 정보」 → 「실행」.

맥

  1. zip 내려받아 압축 풀기

    다운로드 폴더에서 더블클릭하면 풀립니다.

  2. 시작.command 우클릭 → 열기

    처음 한 번 「확인되지 않은 개발자」가 뜨면 우클릭 → 열기 → 열기. 그다음부턴 더블클릭.

  3. ffmpeg 없다고 하면

    터미널에 brew install ffmpeg 입력 후 다시 실행. (Homebrew가 없으면 brew.sh)

화면 주소는 http://127.0.0.1:8790/ — 내 컴퓨터에서만 열리는 주소입니다. 끌 때는 화면의 「⏻ 종료」.

첫 실행 — 딱 네 번만

  1. 「설정」 탭에 키 넣고 「저장하고 점검」

    Gemini 키, 쿠팡파트너스 Access·Secret. 점검 결과가 초록으로 바뀌면 됩니다.

  2. 「유튜브 연결」 → 구글 계정으로 허용

    「확인되지 않은 앱」이 뜨면 고급 → (안전하지 않음)으로 이동 → 허용. 테스트 사용자 등록이 안 돼 있으면 이 화면이 안 뜹니다.

  3. input_videos 폴더에 내 영상 넣기

    mp4 또는 mov. 제품이 잘 보이는 10~60초 영상이 좋습니다.

  4. 「쇼핑쇼츠」 탭에서 영상 고르고 키워드 적고 「실행」

    쿠팡 주소를 비우면 후보를 보여 주니 영상 속 제품과 같은 것을 고르세요. 공개 상태는 안정될 때까지 「일부공개」를 권합니다.

쇼츠 썸네일: 유튜브가 쇼츠의 맞춤 썸네일을 API로 안 받는 경우가 있습니다. 결과 화면의 「썸네일 파일 보기」로 thumb.jpg를 찾고, 「썸네일 확인 (스튜디오)」에서 썸네일 칸에 끌어다 놓고 저장하면 됩니다. 30초 걸립니다.

지켜야 하는 것

  • 본인이 촬영했거나 허락받은 영상만 씁니다. 판매자 영상, 남의 얼굴이 나오는 영상은 올리면 안 됩니다.
  • 쿠팡파트너스 고지문은 자동으로 설명란 첫 줄에 들어갑니다. 지우지 마세요.
  • 대본은 「써 봤다·내돈내산」 같은 거짓 체험 표현과 「최저가·마감임박」 같은 확인 안 되는 말을 쓰지 않도록 되어 있습니다.
  • 속보 영상은 확인 안 된 내용을 확인 안 됐다고 말하고, 피의자·피해자 신상은 넣지 않습니다.
  • 키·토큰은 내 컴퓨터에만 있습니다. 프로그램 폴더를 남에게 통째로 보내지 마세요.

자주 묻는 질문

돈이 드나요?

프로그램은 무료입니다. Gemini API·타입캐스트는 각자 계정의 사용량만큼 과금됩니다(Gemini는 무료 한도가 있음). 유튜브·쿠팡파트너스는 무료.

「유튜브 연결」에서 허용 화면이 안 떠요

운영자 앱의 테스트 사용자로 등록돼야 합니다. 구글 계정 주소를 운영자에게 알려 주세요. 등록 후 다시 「유튜브 연결」.

쿠팡 검색 결과가 없다고 나와요

키워드를 더 일반적인 말로 바꿔 보세요(예: 「스텐 반죽판」 → 「반죽판」). 쿠팡 검색은 시간당 횟수 제한이 있어 같은 키워드는 24시간 재사용합니다.

영상에 얼굴이 나오면요?

올리지 마세요. 프로그램은 얼굴을 지우지 않습니다. 손·몸만 나오는 영상은 괜찮습니다.

포트 8790을 못 연다고 나와요

이미 켜져 있는 겁니다. 브라우저에서 http://127.0.0.1:8790/을 열거나, 화면의 「종료」 후 다시 실행.

윈도우에서 한글이 깨져 보여요

검은 창의 글자만 깨지는 것이면 동작에는 문제없습니다. 화면(브라우저)은 정상입니다. 창을 UTF-8로 맞춰 두었습니다.

업데이트는 어떻게 하나요?

새 zip을 받아 압축 풀고, 옛 폴더의 config·input_videos·output 폴더를 새 폴더로 옮기면 됩니다.
